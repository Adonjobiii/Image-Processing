This project presents a comprehensive implementation of fundamental image processing techniques utilizing Python, OpenCV, and Matplotlib within a Google Colab environment. It enables users to interactively upload images and apply a sequence of processing operations, including Gaussian Blurring, Median Filtering, Canny and Laplacian Edge Detection, Binary and Otsu’s Thresholding, as well as Morphological Operations such as Opening for noise reduction. Each method is demonstrated with side-by-side visual comparisons of the original and processed images, offering clear insights into the effects of each technique. Designed to be both educational and practical, this project serves as a valuable resource for those seeking to explore or teach essential concepts in computer graphics and image processing.
